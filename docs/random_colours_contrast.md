## random colours contrast

Test a foreground and background colour for WCAG AA and AAA contrast requirements

### Synopsis

Given 2 solid colours, one as foreground, the other as background,
it will test the contrast and generate a report based on WCAG AA and AAA compliance.
If you are working with semi-transparent colours, use the 'colours stacked' command to
resolve the painted colour.

```
random colours contrast [flags]
```

### Options
